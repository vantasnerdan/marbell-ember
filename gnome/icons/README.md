# Marbell Ember icons

`./gnome/icons/install.sh` derives folder/places PNGs from the installed Yaru-dark and Yaru assets, preserving all shipped sizes, scale factors and alpha masks. The folders retain Yaru's shapes with lighter slate fronts (`#5B6B8C`), a clearly visible coral upper flap and bright special-folder emblems. Plain 16px special-folder assets borrow their 24px Yaru emblem. Trash/full and network assets are included; no new glow or shadow is drawn. Everything else inherits `Yaru-dark,Yaru,hicolor`; symbolic icons remain theme-tinted and app brand icons remain unchanged. No generated PNGs are committed.

The default destination is `~/.local/share/icons/Marbell-Ember`, respecting `XDG_DATA_HOME`. The script validates every generated icon through GTK's resolver. It selects the theme only when its combined pixel/index signature matches the build visually checked in Nautilus and recorded in [`nautilus-verified.json`](nautilus-verified.json). A changed Yaru build installs the assets but selects Yaru-dark pending a new visual check. This prevents an untested future source conversion from silently becoming the selected icon theme.

For an updated build, use `gnome/shell/preview.py --icons /path/to/candidate/Marbell-Ember --output /tmp/ember-preview` with the candidate selected only inside its private settings environment. Inspect its Nautilus screenshot, then run `/usr/bin/python3 gnome/icons/validate.py ~/.local/share/icons/Marbell-Ember`. After confirming the result, update the signature and provenance in `nautilus-verified.json` and rerun the installer. `preview.py THEME --output strip.png` renders 16/24/32/48px rows at actual size on navy. The installer rebuilds the cache and briefly changes/reselects an already active Marbell-Ember icon theme so open GTK windows refresh without a logout.

Use `MARBELL_EMBER_BACKUP_DIR=/path/to/snapshot ./gnome/icons/install.sh` with the desktop installer. Run `./gnome/icons/revert.sh` with the same variable to restore the exact previous icon-theme setting and any previous directory. Without that variable, both scripts use the component's latest snapshot below `${XDG_STATE_HOME:-$HOME/.local/state}/marbell-ember/icons/`. Repeated calls are idempotent. No other interface settings are changed.

The scripts use system Python, Pillow, GTK4 GI and `/usr/bin/gtk-update-icon-cache` when available; they install no dependencies. `install.py` imports the snapshot helper from the sibling `gnome/shell/` directory, so keep both directories in the checkout. Derived icons retain Yaru's CC-BY-SA-4.0 attribution and full licence in the generated theme directory.

`nautilus-verified.json` is shipped because the installer reads its approved pixel/index hash at runtime. Other validation reports are local run records and are ignored by Git.
